# Portfolio visual assets

The header and sharing image are original vector artwork for this repository. Editable SVG sources are included alongside the 1280 × 640 social-preview PNG.

The preview images are screenshots of the saved Expo apps, cropped to the app viewport and placed in a consistent frame. Star Rush, PainterStarter, and Clock were captured on web; RouteMapper was captured in the Snack iOS simulator. The application UI is preserved.

| Image | Source | Captured state |
| --- | --- | --- |
| PainterStarter | [Saved Snack](https://snack.expo.dev/@siddv19/painterstartervadali) | Drawing with rectangle, circle, and line tools; move tool selected |
| Star Rush | [Saved Snack](https://snack.expo.dev/@siddv19/tiltgamevadali) | Start screen and game rules |
| RouteMapper | [Saved Snack](https://snack.expo.dev/@siddv19/routemapperarigovadali?platform=ios) | iOS simulator tracker map before recording a run; zero distance/time and empty pace |
| Clock | [Saved Snack](https://snack.expo.dev/@siddv19/clockvadali) | Paused during a work interval |

The main portfolio gallery features Star Rush and RouteMapper. PainterStarter and Clock previews remain on their individual project pages.

These captures show interface states. They do not represent physical-device verification of sensors, GPS, audio, or haptics.
